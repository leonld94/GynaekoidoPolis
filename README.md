# GynaikoeidoPolis Γυναικοειδόπολις

자원을 확보하고 건물을 세우며 주민과 생산을 관리해 정착지를 유지·확장하는 3D 쿼터뷰 생존 건설 경영 시뮬레이션<br>

이었으나 개발경험 부족으로 여러 기능 구현에서 문제가 발생하고 있으므로 핵심기능을 잠시 동결하고 정말 최소한의 Prototype으로 변경.  
그러므로 해당 문서와 docs에 작성된 문서들과는 당장은 조금 구현이 달라질 예정.

---

## 게임 개요

- 장르: 생존 건설 경영 시뮬레이션
- 시점: 3D 쿼터뷰
- 개발 단계: 초기 프로토타입
- 사용 엔진: Unity 6 (`6000.5.7f1`)

### 핵심 게임 루프

자원 확보 → 건물 건설 → 주민 배치 → 생산 → 인구 유지 및 확장

### 튜토리얼에서 제공할 첫 번째 목표

모든 Thnetoi가 집을 가지고, Thnetoi와 Gynaikoeideis가 소비할 충분한 식량을 생산한다.

## 현재 개발 상태

| 영역 | 상태 | 설명 |
| --- | --- | --- |
| 시간 | 부분 구현 | 고정 틱, 일시정지, `1x`·`2x`·`3x`·`6x` 배속 |
| 카메라 | 부분 구현 | 이동, 회전, 높이 조절 |
| 맵·타일 | 설계 및 데이터 모델 작성 중 | 청크 크기와 기본 직렬화 데이터 정의 |
| 자원·건설·주민·직업·생산 | 계획 | 첫 마일스톤에서 구현 예정 |
| 저장·불러오기 | 계획 | 맵 및 시뮬레이션 상태 저장 예정 |

세부 작업 순서와 장기 계획은 [개발 로드맵](docs/Roadmap.md)에서 관리

## 실행

1. Unity에서 프로젝트를 연 후 Play Mode로 실행

### 현재 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 카메라 이동 |
| `Q` `E` | 카메라 회전 |
| 마우스 휠 | 카메라 높이 조절 |
| `Space` | 일시정지 전환 |
| `1` `2` `3` `4` | 각각 `1x` `2x` `3x` `6x` 배속 선택 |

## 현재 범위에서 제외하는 기능

- 전투와 외교
- 멀티플레이
- 다중 정착지
- 종교, 신앙, 정치 공동체, 정부 체제 등 복잡한 사회 구조
- 복잡한 기술 및 정책 트리
- 질병, 가뭄, 지진 등 무작위 위기
- 이민족 이동이나 침략과 같은 후반 위기
