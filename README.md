# Gynaekoidopoils Γυναικοειδόπολις
장르: 생존 건설 경영 시뮬레이션
시점: 3D 쿼터뷰
핵심 루프:
  자원 확보 → 건물 건설 → 주민 배치 → 생산 → 인구 유지/확장

핵심 시스템:
  - 시간(계절)
  - 자원
  - 건설
  - 주민
  - 직업
  - 생산
  - 물류: 동선 최적화 필요.
  - 식량/생존
  - 저장/불러오기

초기 목표:
  "나무꾼이 나무를 생산해 뗄깜을 유지하고 농부가 식량을 생산해 식량을 유지하며
   집을 지속적으로 지어 인구 증가를 유지할 수 있다."

당장은 하지 않을 것:
  - 전투
  - 외교
  - 멀티플레이
  - 다중 정착지
  - 종교/신앙/정치공동체/정부체제 등 이점과 불리점을 유발하는 복잡한 사회구조
  - 복잡한 기술/정책 트리
  - 질병/가뭄/지진 등 랜덤 인카운터 위기
  - 이민족 대이동 또는 침략 등 정착지 완성도를 평가하는 후반위기

3. 타일시스템
4. 오브젝트
5. 이동
6. 기본 UI
7. 맵저장
8. Scene 생성


## 첫 마일스톤
1. 게임을 킨다
2. 세이브파일을 연다(또는 튜토리얼 Scene이 열린다)
3. 건물건설을 예약한다
4. 건물을 건설한다
5. 직업에 인구를 넣는다
6. 자원이 모이는 것을 확인한다

### 첫 마일스톤 이후 시간 시스템 보완
- 긴 프레임이 발생했을 때 밀린 틱을 전부 처리할지, 프레임당 최대 처리 틱 수를 제한할지 정책을 결정한다.
- `Simulation.Tick()`에서 건설, 인구, 자원 등 시뮬레이션 시스템을 실행하는 순서와 같은 틱에 발생한 변화가 언제 반영되는지 규칙을 정의한다.
- 줌인 줌아웃 수치만큼 카메라 각도 조절. 줌인 많이 할 수록 수평을 보고 줌아웃 많이 할 수록 연직방향을 보도록.
- 카메라 회전이 카메라를 중심으로 하는 것이 아니라 시야를 중심으로 하도록 변경. (위에거랑 합치면 작동방식 고민좀 해야할듯)
