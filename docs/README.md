# 프로젝트 문서 폴더

해당 폴더에는 시스템 설계, 프로젝트 용어, 개발 계획을 기록함

## 문서 상태 기준

- **구현:** 코드에 반영되어 현재 동작하는 내용
- **결정:** 구현 전이지만 채택된 설계
- **계획:** 구현할 방향은 정했지만 아직 코드에 반영되지 않은 내용
- **미결정:** 선택지나 세부 규칙을 더 검토해야 하는 내용

## 작성 원칙

- 현재 코드의 동작과 향후 계획을 구분
- 확정되지 않은 내용은 `미결정 사항`에 기록
- 구현이 바뀌면 관련 시스템 문서를 함께 갱신
- 고유 명칭의 표기와 의미는 [용어집](Glossary.md)을 기준으로 함
