# 용어집

> 상태: 작성 중

프로젝트에서 사용하는 그리스어 계열 고유 명칭과 코드 용어를 정리. 세부 설정이 확정되지 않은 항목은 임시 정의로 표시.

## 프로젝트 표기

| 용도 | 표기 |
| --- | --- |
| 작품명 | `Γυναικοειδόπολις` |
| 폴더·저장소·코드용 프로젝트명 | `GynaikoeidoPolis` |
| 개체 단수 및 C# 타입 | `Gynaikoeides` |
| 그리스어식 복수 | `Gynaikoeideis` |

프로젝트의 그리스어 계열 고유 명칭은 고전 그리스어를 라티움 문자로 전사. 코드에서는 장음과 악센트 부호를 생략하고 PascalCase를 사용.

## 시뮬레이션 개체

| 용어 | 의미 | 상태 |
| --- | --- | --- |
| `Soma` (`σῶμα`, 복수 `Somata`) | 물리적인 몸을 가지고 맵에 존재하는 개체의 상위 개념 | 결정 |
| `Oikodomema` (`οἰκοδόμημα`, 복수 `Oikodomemata`) | 주거지, 생산 시설 등 건물 또는 구조물 | 결정 |
| `Thnetos` (`θνητός`, 복수 `Thnetoi`) | 자연적인 필멸 `Soma` | 검토안 |
| `Organon` (`ὄργανον`, 복수 `Organa`) | 특정 목적을 수행하도록 만들어진 인공 `Soma` | 검토안 |
| `Gynaikoeides` (`γυναικοειδής`, 복수 `Gynaikoeideis`) | 필멸 종족을 부양하기 위해 만들어진 `Organon`의 총칭 | 검토안 |

### 검토 중인 개념 계층

```text
Soma
├─ Thnetos
│  ├─ Anthropos
│  └─ Mytikos (Ratkin) | Myeus | Hemimys
└─ Organon
   └─ Gynaikoeides
```

### `Organon` 명칭 배경

`Organon`은 도구, 기구라는 뜻. 아리스토텔레스는 『니코마코스 윤리학』 8권 11장 1161b4–5에서 노예를 `empsychon organon`(살아 있는 도구)라고 표현. 『정치학』 1권 4장 1253b27–37에서는 생명 없는 도구와 살아 있는 도구를 구분하고, 도구가 명령을 이해하거나 필요를 예측하여 스스로 일한다면 주인에게 노예가 필요하지 않을 것이라는 언급을 함. 이런 연유에서  스스로 일하는 도구라는 의미에서 부여한 이름.

- [《니코마코스 윤리학》 그리스어 원문](https://www.glossa.edu.gr/digitalResources/ancient_greek/library/browse.html?page=96&text_id=78)
- [《정치학》 1253b 그리스어 원문](https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Aabo%3Atlg%2C0086%2C035%3A1%3A1253b)

### 검토 중인 `Organon` 유 개념
- 현대/미래 인간형 로봇 Gynaikoeides
- 구체관절 시계태엽 구조 자동인형 amphipolos
- 증기 동력 automaton

## 표기 원칙

- 코드 형식의 단수 명칭은 PascalCase로 쓴다.
- 코드 타입명은 단수 기본형을 사용한다.
- 한국어 문장에서는 그리스어 복수형 대신 `Gynaikoeides 개체들`처럼 단수 기본형을 집합적으로 사용할 수 있다.
- 그리스어 문법상의 복수형이 필요한 경우 용어집에 확정된 형태를 사용한다.
- 아직 의미가 확정되지 않은 그리스어 명칭은 구현 전에 이 문서에서 정의를 확정한다.
