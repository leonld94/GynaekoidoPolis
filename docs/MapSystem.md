# 맵 시스템

## Map class
- 가져야하는 것:
    - 시드 정보(절차적 생성을 쓸거니까 즉 Geomorphomata, Geoschemata)
    - 지물(Oikodomemata) 정보
    - 로딩된 청크 정보
    - 절차적 생성 코드 또는 클래스
    - 타일 정보
        - 이동 가능/불가 정보
        - 건설 가능/불가 정보

- 건설 예약 정보는 Simulation에 있으면 될 듯

## Chucnk 시스템
- 무한확장을 위한 시스템임.
- 하나의 청크는 128 x 128 타일로 이루어짐.
- 맵의 로딩과 연산 단위는 청크. 맨 처음에는 네 개의 청크만이 열려있음.(1,2,3,4사분면)
- 청크는 어떤 Geoschema인지는 이미 세계 전도에 할당되어있지만, 어떤 Geomorphomata로 이루어져있는지는 해당 청크를 로딩하지 않으면 알 수 없음.(림월드처럼)
- 줌 아웃을 크게 하면 세계 전도로 바뀌고 줌 인을 크게 하면 개별 지도로 바뀌는 형상.(임페라토르 롬처럼)
    - 힘들 수도 있겠다. 그냥 맵을 세계 전도랑 인게임 두 개 만들고 Chunk Loading은 세계전도에서 하는걸로 할까.(림월드처럼)

## 세계 전도
- 접근가능한 세계는 일단 직사각형임. 지구처럼 바다가 70%라는 설정으로 하자. 다이슨 스피어 프로그램처럼 구라면 좋겠지만 그건 지금 당장은 복잡함.

## 타일 시스템
- TileSystem이나 GridSystem 클래스가 담당?
- Simulation이 멤버로 가지는 Map class의 멤버로 Tile을 가지거나 하면 될 것 같은데
- 타일에 영향받는 것들: Oikodomemata. 타일에 맞게 형성됨
- 타일에 영향받지 않는 것들: Somata, Geomorphomata. 타일을 따라가지 않음.(Banished처럼)

### 건설 가능 구역과 불가 구역
- 이미 무언가가 타일을 차지하고 있으면 건설이 불가함
- 타일을 차지하는 것들:
    - Geomorphomata: 맵이 만들어지면서 선제적으로 차지중
    - Oikodomemata
- 맵 크기는 256x256이니까 2차원 Boolean Array가 청크들을 대변하면 될듯?

### 건설 시도시 건드는 것들
1. 마우스 포인터가 어딘가를 가리킴
2. 그 청크가 로딩이 되어있는가?
3. 해당 청크의 타일이 비어있는가?
