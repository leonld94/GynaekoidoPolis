# 시간 시스템

> 상태: 부분 구현  
> 관련 코드: `SimulationClock.cs`, `SimulationController.cs`, `Simulation.cs`, `SimulationClockData.cs`

## 목적

렌더링 프레임과 독립적인 고정 틱을 기준으로 게임 내 시뮬레이션 시간을 진행한다. 일시정지와 배속은 시뮬레이션 틱이 호출되는 빈도에만 영향을 준다.

## 범위

시간 시스템은 다음을 담당한다.

- 현재 틱과 게임 내 시각의 계산
- 일시정지 상태 관리
- 게임 배속 선택
- 매 틱 `Simulation.Tick()` 호출

화면 우하단 등에 표시할 현실 시각은 게임 내 시간과 별개이며 UI 계층에서 처리할 계획이다.

## 확정된 시간 규칙

| 단위 | 값 |
| --- | ---: |
| `1x`에서 초당 틱 | 10틱 |
| 게임 내 1시간 | 25틱 |
| 게임 내 1일 | 24시간, 600틱 |
| 게임 내 1년 | 15일, 9,000틱 |
| `1x`에서 게임 내 1년 | 현실 시간 15분 |

`SimulationClock`은 `CurrentTick`, `Hour`, `Day`, `Year`를 보유하며 틱이 진행될 때 시간 단위를 갱신한다.

## 배속 처리

지원하는 상태는 일시정지와 `1x`, `2x`, `3x`, `6x`이다.

배속이 바뀌어도 기준 틱 간격 `T₀ = 0.1초`는 변경하지 않는다. 대신 매 프레임 누적 시간에 현재 배속을 곱한다.

```text
누적 시간 += Time.unscaledDeltaTime × 현재 배속

누적 시간이 0.1초 이상인 동안:
    누적 시간 -= 0.1초
    Simulation.Tick() 호출
```

따라서 `2x`에서는 현실 시간 1초당 20틱, `6x`에서는 60틱이 진행된다. Unity의 `Time.timeScale` 변경 여부에 영향을 받지 않도록 `Time.unscaledDeltaTime`을 사용한다.

## 일시정지와 배속 선택

- `Space`를 누르면 일시정지 상태를 전환한다.
- 일시정지 중에는 누적 시간과 시뮬레이션 틱이 진행되지 않는다.
- 일시정지 중에도 배속을 선택할 수 있다.
- 일시정지를 해제하면 마지막으로 선택한 배속으로 진행한다.
- 숫자 `1`, `2`, `3`, `4`는 각각 `1x`, `2x`, `3x`, `6x`를 선택한다.

## 현재 구현

- `SimulationController`가 프레임 시간과 배속을 누적하고 `Simulation.Tick()`을 호출한다.
- `Simulation.Tick()`이 `SimulationClock.AdvanceTick()`을 호출한다.
- `SimulationClock`이 틱을 게임 내 시각으로 변환한다.
- 새 시뮬레이션은 일시정지 및 `1x` 선택 상태로 시작한다.

## 미결정 사항

- 긴 프레임 이후 밀린 틱을 모두 처리할지, 프레임당 최대 처리 틱 수를 둘지 결정해야 한다.
- `Simulation.Tick()` 안에서 건설, 인구, 자원 등 하위 시스템을 실행하는 순서를 정해야 한다.
- 같은 틱에 발생한 상태 변경을 즉시 반영할지 다음 틱에 반영할지 정해야 한다.
